# Sai Ram Gottipati — Data Engineering Command Center

Responsive personal portfolio built with React, TypeScript, Vite, Tailwind CSS and Framer Motion.

## Run locally

1. Install Node.js 20+.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Customize

- `src/App.tsx`: edit profile, experience, skills, metrics and project cards.
- `src/styles.css`: edit colors, typography, layout and mobile styles.
- `public/resume.pdf`: add your current resume PDF to enable the resume download.
- The GitHub profile link points to [sairam-gottipati](https://github.com/sairam-gottipati).
- The Projects section explicitly labels *concepts* until you build and publish actual projects. Add repo links only when ready.

## Publish

Run `npm run build`. Deploy the `dist/` output to Vercel or Netlify, or connect your GitHub repository to either platform.

## Content note

Professional history and impact metrics are adapted from the supplied resume. Project cards are proposed public demonstrations, not claims that code has already been published. No proprietary healthcare or insurance data is included.
