## How I approach engineering

- **Start with the business need.** Connect ingestion, transformation, and data modeling decisions to the analytics the team needs.
- **Make reliability part of the design.** Build validation, reconciliation, orchestration, and monitoring into the pipeline.
- **Treat data quality and governance as daily work.** Make data accurate, discoverable, and accessible to the right people.
- **Keep improving.** Measure processing time, latency, and operating costs, then address the bottlenecks.

```bash
npm run preview
```

To rebuild and publish the website to GitHub Pages:

```bash
npm run deploy
```

Deployment requires GitHub write access to this repository. GitHub Pages serves the compiled website from the `gh-pages` branch. Source code and this README are maintained on `main`.

Edit `src/App.tsx` to update the profile and experience, and `src/styles.css` to adjust the design. Add a resume PDF at `public/resume.pdf` and rebuild to show the resume download button. The site is configured for the `/sairam-gottipati-data-engineer/` URL path.
